# Gestión de Estudiantes

Aplicación CRUD académica construida con HTML, CSS y JavaScript puro.

## Funcionalidades
- Crear, consultar, editar y eliminar estudiantes.
- Búsqueda por nombre, matrícula, correo o carrera.
- Filtro por estado (Activo/Inactivo).
- Validación de campos y matrícula única.
- Persistencia con `localStorage` del navegador.
- Diseño adaptable a móviles y escritorio.

## Ejecutar
1. Descarga o clona el repositorio.
2. Abre `index.html` en un navegador moderno.
3. No necesita instalación ni servidor para la versión básica.

> Los datos se almacenan únicamente en el navegador donde se utiliza la aplicación. No es una base de datos compartida entre usuarios.

## Estructura
- `index.html`: estructura de la interfaz.
- `styles.css`: estilos y diseño responsive.
- `app.js`: lógica CRUD, validaciones y almacenamiento local.
